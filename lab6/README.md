# Lab: Covariance and Correlation Analysis

## Description
This lab focuses on understanding and analyzing relationships between variables using covariance and correlation, with visualizations for better insights.

## Questions

1. [Covariance calculation and scatter plot](dataset_covariance.py)  
   Create a dataset of study hours and marks, calculate covariance, and visualize with a scatter plot.

2. [Correlation coefficient and regression plot](correlation_coefficient.py)  
   Compute correlation, interpret its meaning, and display the relationship using seaborn regression.

3. [Temperature and ice-cream sales covariance](temp.py)  
   Generate temperature and sales data, calculate covariance, and plot their relationship.

4. [Correlation comparison and interpretation](temp_vs_icecream.py)  
   Calculate correlation for temperature-sales data, compare it with covariance, and explain interpretability.

5. [Random datasets covariance and correlation](random_data_analysis.py)  
   Create unrelated datasets, compute covariance and correlation, and visualize their scatter plot.

6. [Height and weight dataset analysis](height_weight_analysis.py)  
   Load data, calculate mean, variance, covariance, correlation, and plot using seaborn jointplot.

7. [Linear vs random variable comparison](linear_vs_random.py)  
   Create datasets with linear and random variables, compute covariance and correlation, and compare plots.
