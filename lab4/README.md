# Lab 4: Advanced Techniques in Python

## Description
This lab explores advanced Python features such as sorting methods, list comprehensions, generators, randomization, regular expressions, and functional programming tools.

## Questions

1. [Sort student marks](qns1.py)  
   Arranges a list of student scores from highest to lowest using built-in sorting methods.

2. [Even numbers using list comprehension](qns2.py)  
   Generates a list of even numbers within a given range using a concise Python expression.

3. [Number generator](qns3.py)  
   Demonstrates lazy evaluation by yielding numbers one at a time from a sequence.

4. [Random volunteer selection](qns4.py)  
   Randomly selects a fixed number of students from a list without repetition.

5. [Uppercase word extractor](qns5.py)  
   Uses regular expressions to find words that begin with capital letters in a paragraph.

6. [Pairing and total score calculation](qns6.py)  
   Combines names and scores and computes the overall total using functional programming tools.
