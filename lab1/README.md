# Lab 1: Basics of Python

## Description
This lab introduces basic Python concepts such as data types, control structures, functions, and loops.

## Questions

1. [Sum of two numbers](qns1.py)  
   Takes two user inputs and performs a basic arithmetic addition.

2. [Palindrome checker](qns2.py)  
   Verifies whether a given string reads the same forward and backward.

3. [Prime numbers](qns3.py)  
   Identifies and displays all prime numbers within a specified range.

4. [Fibonacci series](qns4.py)  
   Generates a sequence where each number is the sum of the previous two.

5. [GCD calculator](qns5.py)  
   Uses a function to compute the greatest common divisor of two numbers.

6. [Even or odd check](qns6.py)  
   Determines the parity of a number using conditional logic.

7. [Largest element in a list](qns7.py)  
   Finds the maximum value from a user-provided list of numbers.

8. [Leap year validation](qns8.py)  
   Checks whether a given year satisfies leap year conditions.

9. [Temperature conversion](qns9.py)  
   Converts Celsius temperature into Fahrenheit or Kelvin based on user choice.

10. Advanced programs:
    - [Birth year and leap year check](leap_year.py)  (main.py) (basic.py)
      Calculates birth year from age and verifies if it was a leap year.
    - [BMI calculator](bmi_calculate.py)  
      Computes BMI using flexible height and weight units and classifies the result.
    - [Army eligibility check](army_eligibility.py)  
      Evaluates eligibility based on age and BMI constraints.
