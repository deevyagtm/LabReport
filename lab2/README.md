# Lab 2: Data Structures in Python

## Description
This lab focuses on using Python data structures such as lists, tuples, sets, and dictionaries to solve practical problems.

## Questions

1. [Movie ratings analyzer](movie_rating.py)  
   Processes movie–rating pairs to calculate overall statistics and identify top-rated movies.

2. [Unique words collector](word_collector.py)  
   Extracts distinct words from user input, organizes them alphabetically, and counts them.

3. [Student marks manager](marks_manager.py)  
   Manages student scores, computes averages and grades, and ranks top performers.

4. [Inventory tracker](inventory_tracker.py)  
   Simulates a store inventory by updating stock levels and identifying low-stock items.

5. [Word reverser game](word_reversal.py)  
   Modifies a list of words by reversing only those that meet a specific length condition.

6. [Simple path validator](path_validator.py)  
   Verifies whether a given sequence of locations forms a valid path in a connected map.
