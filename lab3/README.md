# Lab 3: File Handling and Exception Handling

## Description
This lab demonstrates file operations in Python along with proper exception handling to manage errors during input, output, and data processing.

## Questions

1. [Basic file read and write](basicreadandwrite.py)  
   Creates a text file, writes multiple lines, reads the content, and safely handles missing file errors.

2. [File processing with exceptions](file_processing.py)  
   Reads numerical data from a file, skips invalid entries, and computes summary statistics.

3. [CSV file handling](csvfilehandling.py)  
   Loads and displays student records from a CSV file while managing file and data errors.

4. [JSON data handling](randwjsonfile.py)  
   Stores student information in a JSON file and retrieves it with proper error handling.

5. [Menu-driven file operations](menudriven.py)  
   Provides an interactive menu to write, read, and append data while handling invalid inputs and file-related exceptions.
