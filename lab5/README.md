# Python Lab: Pandas Basics and Data Handling

## Description
This lab covers essential Pandas operations for loading, inspecting, cleaning, and transforming data.

## Questions

1. [Create and inspect DataFrame](qns1.py)  
   Build a DataFrame and display its first rows and overall shape.

2. [Load CSV and explore data](qns2.py)  
   Read data from a CSV file, list columns, check data types, and view summary stats.

3. [Filter rows and select columns](qns3.py)  
   Extract rows with marks above 60 and select specific columns for display.

4. [Handle missing values](qns4.py)  
   Identify missing data and fill numerical gaps with the mean value.

5. [Detect and remove duplicates](qns5.py)  
   Find duplicate records, remove them, and verify dataset integrity.

6. [Outlier detection and removal](qns6.py)  
   Use the IQR method to detect and exclude outliers from the marks column.

7. [Transform and save dataset](qns7.py)  
   Create a new column by scaling marks, rename columns, and save the cleaned data.
